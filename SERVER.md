# RockiGo с сервером Роки

Пользователь открывает сайт и учится без аккаунта. Имя, очки и результаты тестов остаются в браузере. Вопрос, язык и идентификатор урока отправляются на сервер, где Qwen выбирает подходящее объяснение из учебных материалов. Сайт показывает источник. При недоступности модели остаются подсказки из справочника.

## Подключение к GitHub Pages

1. Запустите сервер из папки `server`. Задайте `ROCKIGO_SITE_ORIGIN` равным адресу GitHub Pages без пути к репозиторию, например `https://my-team.github.io`.
2. Настройте HTTPS-адрес, который направляет запросы на сервер. Сторонний хостинг должен держать модель запущенной на CPU и разрешать запросы длительностью до 100 секунд.
3. Откройте `pages/index.html` текстовым редактором. В строке `<meta name="rockigo-api" content="">` впишите в пустые кавычки HTTPS-адрес сервера, например `https://rocky.example.org`. Загрузите содержимое папки `pages` на GitHub Pages.
4. Откройте вкладку «Роки» на опубликованной странице. Над чатом должно появиться «ИИ Роки подключён». Попробуйте спросить о теме текущего урока.

В папке `pages` лежит демонстрационный HTML без прямых ссылок на PDF и видео из пакета хакатона. Уточните условия публикации у организаторов перед размещением учебных материалов в открытом доступе.

## Запуск сервера в Docker

В папке `server`:

```sh
docker build -t rockigo-rocky .
docker run --rm --name rockigo-rocky -e ROCKIGO_SITE_ORIGIN=https://my-team.github.io -p 127.0.0.1:8080:8080 rockigo-rocky
```

Публичный HTTPS-прокси должен направлять запросы `/capabilities` и `/rocky` на `127.0.0.1:8080` и сохранять заголовок `Origin`. Сборка загружает около 500 МБ весов модели. Ключ облачного ИИ не нужен. Доступ для браузера задан для одного происхождения GitHub Pages. Сервер обрабатывает один запрос к модели одновременно и ограничивает частоту запросов. Лимит применяется по адресу соединения, поэтому через один прокси пользователи могут делить один лимит.

## Запуск без Docker

Используйте Node.js 24 и команду `node --experimental-wasm-jspi server.mjs --api`. Укажите папку модели и среды в `ROCKIGO_RUNTIME`. Размер и точные имена файлов приведены в Dockerfile. По умолчанию сервер слушает на `127.0.0.1:8080`.

Конкурсный офлайн-курс по-прежнему можно открыть как отдельный HTML. В нём подсказки, тесты и прогресс доступны локально.
