# RockiGo с сервером Роки

Пользователь открывает сайт и учится без аккаунта. Имя профиля, очки и результаты остаются в браузере. Подсказки по учебным материалам, номера страниц и команды работают локально. Для свободного диалога браузер отправляет серверу Роки текст сообщения, язык и до четырёх коротких реплик. Если модель распознаёт просьбу выполнить действие, браузер предлагает кнопку подтверждения. Автономный HTML открывается без сервера и логина.

## Локальный чат с Qwen 3.5

Для новой копии проекта скачайте [Qwen 3.5 0.8B Q4_0](https://huggingface.co/ggml-org/Qwen3.5-0.8B-GGUF/blob/main/Qwen3.5-0.8B-Q4_0.gguf) в `source/ai/Qwen3.5-0.8B-Q4_0.gguf`. Распакуйте [архив @wllama/wllama 4.0.0](https://registry.npmjs.org/@wllama/wllama/-/wllama-4.0.0.tgz) в `source/ai/wasm/`, так чтобы появился путь `source/ai/wasm/package/esm/wasm/wllama.wasm`. Контрольные суммы указаны в Dockerfile. Если файлы лежат в другом месте, задайте `ROCKIGO_RUNTIME` для папки, содержащей `wasm/package/esm`, и `ROCKIGO_MODEL_PATH` для файла модели.

```sh
node build.mjs RockiGo.html
node --experimental-wasm-jspi server.mjs --local-ai
```

Откройте `http://127.0.0.1:8776/`. Модель использует локальный CPU. Первое сообщение может ждать загрузку весов. API модели слушает только `127.0.0.1` и проверяет ключ, который сервер генерирует при каждом запуске. Для отдельного совместимого API на этом же компьютере, например llama.cpp, задайте `ROCKIGO_LLAMA_URL`, `ROCKIGO_LLAMA_KEY` и `ROCKIGO_LLAMA_MODEL` и запустите сервер без `--local-ai`.

## Чат на GitHub Pages

В сборке `--public` Роки может работать прямо в браузере. Кнопка «Включить ИИ Роки» загружает Qwen 3.5 0.8B (563 МБ) и среду Wllama. Запросы к модели обрабатываются на устройстве. Лучше использовать свежий Chrome или Edge.

### Cloudflare Workers AI

Worker из `cloudflare/` обрабатывает свободный диалог через Qwen 3.8 27B. `AI` — привязка Workers AI, поэтому ключ модели в браузере не нужен. Сайт передаёт текст сообщения, язык и до четырёх коротких реплик. Команды и ответы по материалам курса выполняются в браузере.

Из корня репозитория после входа в Cloudflare:

```sh
npx wrangler deploy --config cloudflare/wrangler.jsonc
```

Укажите выданный HTTPS-адрес `workers.dev` в `ROCKIGO_API_URL` при сборке `node build.mjs index.html --public`. Worker принимает только настроенный origin GitHub Pages и ограничивает число запросов. Для бесплатной работы используйте тариф Workers Free. [Лимиты Workers AI](https://developers.cloudflare.com/workers-ai/platform/pricing/).

### Отдельный сервер для GitHub Pages

1. Запустите API из корня репозитория. Задайте `ROCKIGO_SITE_ORIGIN` равным адресу GitHub Pages без пути к репозиторию, например `https://my-team.github.io`.
2. Настройте HTTPS-адрес, который направляет запросы на сервер. Сторонний хостинг должен держать модель запущенной на CPU и разрешать запросы длительностью до 100 секунд.
3. Задайте `ROCKIGO_API_URL` равным публичному HTTPS-адресу сервера, например `https://rocky.example.org`. Из корня выполните `node build.mjs index.html --public` и опубликуйте корень на GitHub Pages.
4. Откройте вкладку «Роки» на опубликованной странице. Над чатом должно появиться «ИИ Роки подключён». Для проверки диалога напишите «Как прошёл твой день?», а для проверки навигации — «Где мои тесты?».

Публичный HTML включает номера страниц и библиографические ссылки. Офлайн-курсы с конкурсными материалами собираются отдельно.

## Запуск сервера в Docker

Из корня репозитория:

```sh
docker build -t rockigo-rocky .
docker run --rm --name rockigo-rocky -e ROCKIGO_SITE_ORIGIN=https://my-team.github.io -p 127.0.0.1:8080:8080 rockigo-rocky
```

Публичный HTTPS-прокси должен направлять запросы `/capabilities`, `/rocky/chat` и `/rocky` на `127.0.0.1:8080` и сохранять заголовок `Origin`. Сборка загружает около 500 МБ весов модели. Ключ облачного ИИ не нужен. Доступ для браузера задан для одного происхождения GitHub Pages. Сервер обрабатывает один запрос к модели одновременно и ограничивает частоту запросов. Лимит применяется по адресу соединения, поэтому через один прокси пользователи могут делить один лимит.

## Запуск без Docker

Установите модель как для локального чата, задайте `ROCKIGO_SITE_ORIGIN` и запустите `node --experimental-wasm-jspi server.mjs --api --local-ai`. По умолчанию сервер слушает на `127.0.0.1:8080`.

Конкурсный офлайн-курс по-прежнему можно открыть как отдельный HTML. В нём подсказки, тесты и прогресс доступны локально.
