# RockiGo

Мобильное учебное приложение по геологии. Для ученика аккаунт не нужен. Имя, язык, настройки, очки и результаты остаются в браузере.

## Открытие сайта

Для GitHub Pages публикуйте корень репозитория. Готовая страница — `index.html`. Для локального просмотра можно запустить статический HTTP-сервер в корне или собрать самостоятельный HTML командой `node build.mjs RockiGo.html`. Для пересборки GitHub Pages используйте `node build.mjs index.html --public`.

На главной и во вкладке «Роки» 3D-модель непрерывно повторяет анимацию. На приветствие и учебную подсказку подсветка вокруг Роки откликается. При включённой настройке уменьшения движения модель остаётся неподвижной. Для просмотра без WebGL используется иллюстрация Роки.

## Сервер Роки

Команды Роки и подсказки со страницами источников выполняются в браузере, в том числе в автономном HTML. Для свободного диалога разверните сервер из корня репозитория по HTTPS и укажите его адрес в метатеге `rockigo-api` файла `index.html`. Параметр сервера `ROCKIGO_SITE_ORIGIN` принимает адрес GitHub Pages без пути к репозиторию. Подробные инструкции находятся в `SERVER.md`.

Для отдельного просмотра конкурсного пакета предусмотрена локальная версия. В этот репозиторий входят демонстрационные задания с номерами страниц. Файлы глав, ссылки на оригиналы и конкурсные видео хранятся отдельно.

Конвейер собирает отдельные офлайн-курсы по обучающей и контрольной главам из Markdown/PDF. [Запуск и результаты](pipeline/README.md).

3D-просмотр использует [Model Viewer](https://github.com/google/model-viewer) версии 4.1.0. Текст лицензии прилагается в `assets/LICENSE-model-viewer.txt`.
