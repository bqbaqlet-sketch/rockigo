# RockiGo — тестовый прогон

Замороженная версия — training-freeze-2026-11-26, b180740e45938e2bcc995dab655b02aa6fb9f3ed.

Скачайте каталог целиком и откройте index.html в браузере. Рядом с каждым результатом доступны учебный слой, маршрутизация, таблица покрытия и отчёт. Три демо-курса открываются без сети. Исходные конкурсные книги хранятся отдельно. Страницы относятся к меткам Markdown, включая поле page_pdf в официальной схеме.

Первичный прогон Asquith остановился на странице 146, содержащей только рисунок. Повтор с перегруппировкой 140 и 141–146 собрал все 18 страниц. Автоматическая сверка сопоставила цитаты с Markdown. Элементы для просмотра сканов перечислены в review.csv.

Ролики сделаны отдельно после прогона и привязаны к узлам автоматически собранного слоя. Автоматическая маршрутизация сохранена в исходном виде. Предрендерное подтверждение ментора не получено. Использован локальный Microsoft Irina Desktop. Дополнение доменного пакета к движку не подключалось.

manual_edits.csv — журнал. Помеченные оценки отражают время работы с ассистентом, точные человеко-минуты не замерялись. metrics.csv — машинные замеры. manifest.json — входные диапазоны для повтора под замороженным тегом.

Ответ на внешний пакет Asquith — [review/test_asquith_answer.json](review/test_asquith_answer.json). В пакете 86 элементов и 9 кадров. Замороженные функции сверили цитаты и числа 63 утверждений с 18 страницами Markdown. Единственный флаг дословной сверки (C053) снят после пересчёта. Смысл, сценарий и кадры сверены вручную. В теге нет отдельной команды, которая принимает внешний package.json и выдаёт этот формат. Итоговые 19 замечаний прошли review_output.schema.json.
