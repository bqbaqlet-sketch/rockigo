RockiGoО проекте

Глава → курс

Загрузи Markdown и PDF одной главы. Конвейер соберёт учебный слой, проверит ссылки на страницы и подготовит офлайн-курс.

Исходные файлы

Оставь поле пустым, если Markdown уже содержит только нужную главу. Нужны отметки вида <!-- page 9 -->.

Данные главы

Для полного PDF оставь 1. Если файл начинается, например, со страницы 90 по Markdown, укажи 90.

Файлы главы обрабатываются на устройстве. Для первого запуска среде Python нужен интернет.

Результаты

Загрузи свою главу или запусти пример.
